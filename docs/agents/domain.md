# Domain documentation

This is a single-context TypeScript/Bun MCP server.

Before exploring a domain change, read root `GLOSSARY.md` if present and the relevant ADRs in `docs/decisions/`. The existing `docs/decisions/0000-use-adrs.md` records the ADR convention. `EXAMPLE-ADR-*` files are examples, not accepted decisions.

If the glossary is absent, proceed; domain-modeling creates it when terminology is resolved. Use its vocabulary when present. Read `docs/design.md` for the MCP surface and service architecture.

Record architectural decisions under `docs/decisions/`, continuing the numbered files. State conflicts with an accepted ADR explicitly before changing the decision. `AGENTS.md` is the repository agent guide.
